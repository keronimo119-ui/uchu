# 機能1「固有運動タイムラプス」設計書（2026-07-25）

DESIGN.md 機能1。±10万年の早回しで星座が本当に崩れる。

## ゴール（完成条件）
1. 8,920個の実在星が **HYGの実測速度** で動く（直線外挿・±10万年）。架空の動きは禁止。
2. 時間スライダー（新モードではない。宇宙遊泳と🌍地球の夜空で有効／歴史・めぐりでは非表示）。
3. 0年で**現状と完全一致**すること（回帰なし）。
4. 星座線・ハイライト・星タップ・最寄り星HUD も同じ時刻の位置を使う（星だけズレる事故を防ぐ）。
5. 天の川の微光星・惑星・BH・太陽は動かさない（速度データが無い＝架空になるため）。

## 前提（調査済み・再調査不要）
- `stars.js` は自動生成物で **手で編集しない**。1件 = `[x, y, z, 見かけ等級, B-V, 星座index]`（座標は小数2桁・pc・赤道直交J2000）。
- 星座線 `conSegs` は **stars の並び順（index）を参照**している → **並びを変える再生成は禁止**。
- 生成スクリプト(process.js)は残っていない（scratchpadにあったため消失）。
- 距離不明の星は r≒2000pc に置いてある（見かけの方向だけ本物）→ **速度は0**にする。
- index.html 側の星の座標は `pos`(Float32Array) と `starGeo.position` 属性。`absMag` は起動時に `pos` から算出。
- 検証は `window.__U` フック経由。デスクトップのプレビューは描画が止まるので、実機はCDP経由で確認（HANDOFF参照）。

## 第1段階: 速度データを作る（stars.js は触らない・別ファイルを増やす）
- HYG Database v4.1 の CSV をダウンロード（scratchpadに置く。リポジトリには入れない）。
  https://github.com/astronexus/HYG-Database の `hyg/v41/hyg_v41.csv`。列 `vx,vy,vz` は **pc/年**。
- 既存 `stars.js` の8,920件と HYG の行を **突き合わせる**（並び順を保つため）:
  照合キー = 単位方向ベクトルの一致（dot > 0.999995）＋ 見かけ等級の一致（±0.05）。
  距離が既知の星は x,y,z も 0.02pc 以内で一致することを確認する。
- 出力 `starvel.js`（新規・約200KB）: `window.UCHU_DATA.vel=[[vx,vy,vz],...]`
  単位は **pc/百万年**（= HYGの値 ×1e6）・小数4桁・並びは stars と同じ index。
  距離不明星（r>1900pc）と照合できなかった星は `[0,0,0]`。
- **単位の検算（DESIGN指定・合わないなら止める）**: 速度(km/s) = |v(pc/年)| × 977,792。
  - シリウス ≒ 18km/s前後、アークトゥルス ≒ 120km/s前後、バーナード星 ≒ 140km/s前後
  - 全8,920個の中央値が 10〜60km/s の範囲に収まること（外れるなら単位の解釈が誤り）
- 照合できた件数を報告する。**8,000件未満なら不合格**として止める。

## 第2段階: アプリに組み込む
- `index.html` に `<script src="starvel.js?v=1"></script>` を stars.js の直後に追加。
- 状態 `timeYr`（-100000〜+100000・初期0）。`posT` = Float32Array（星の分だけ）。
- `applyTime()`: `posT[i] = pos0[i] + vel[i] * (timeYr/1e6)` を計算し、`starGeo.position` を差し替え。
  **timeYr が変わった時だけ**実行（毎コマ禁止）。スライダー操作中は間引き（約60ms）。
  同時に星座線 `linePos` とハイライト `hlLines` も同じ式で再計算。
- 参照の差し替え: `pickStar` / 最寄り星HUD / 星カードの距離 / `updateApparentMags` は
  **すべて時刻反映後の座標**を見る（`pos` を書き換える方式にすれば参照側の変更は最小で済む。
  元の座標は `pos0` として別に保持し、0年で完全一致することを検証する）。
- UI: ⏱ボタン（既存のボタン群に追加）→ 画面下部にスライダー＋「西暦2026年」「5万年後」等の表示＋
  「いまへ戻す」。歴史/めぐりモードでは隠す。ボタン列の縦位置が増える点に注意（横画面のCSSも既存に合わせる）。
- 音・カメラ・惑星・BH・天の川には触らない。

## 検証
- `__U.setTime(年)` `__U.timeState()` を追加。
- 0年 → 全星の座標が元と**完全一致**（最大誤差 0 であること）。
- +5万年 → おおぐま座の北斗七星の並びが崩れる（星ごとの移動量を数値で確認）。
- アークトゥルス（高速星）の +10万年の移動量が大きいこと（数十度）。
- 60fps 維持（`__U.bench(20)` で1コマの描画時間が現状と同等）。
- 歴史・太陽系めぐりではスライダーが出ないこと。
