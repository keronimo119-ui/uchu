# 計画書: 太陽系めぐりモード（主要6天体・第1弾）

作成: 2026-07-08 ／ 設計レビュー済み（opusサブエージェント・指摘6件採用）
対象ファイル: `index.html` のみ（＋完成時に README.md / docs/HANDOFF.md）

## 完成条件
1. 新ボタン🪐でモードに入ると天体がリアルな3D球で現れ、もう一度押すと遊泳へ戻る
2. **左右フリック**で前/次の天体へ飛行移動（順序: 太陽→地球→月→火星→木星→土星）
3. 見た目は全てプロシージャルシェーダーで実在準拠:
   - 太陽=粒状斑(fbm)+周縁減光+コロナ ／ 地球・月=歴史モードの流用(現在の姿)
   - 火星=赤い大地+白い極冠 ／ 木星=乱流縞+大赤斑 ／ 土星=淡い縞+**環**(実比率1.24〜2.27R・カッシーニの間隙)
   - 実自転軸傾斜(地球23.4°/火星25.2°/土星26.7°等)・実自転周期の共通早回し・金星なし(第2弾)
4. ドラッグで天体のまわりを周回、ピンチで寄り引き（既存fov機構）
5. 到着時に日本語紹介カード自動表示（大きさ・太陽からの距離・ひとこと）。タップで再表示
6. 背景は本物の星空（歴史モード方式の合成）。BHレンズはtour中無効
7. `__U.bench` で 3ms/frame 以下（60fpsの5倍余裕）・実機(Xperia)確認

## スコープ外（やらない）

## 設計の要点（レビュー反映済み）
- **tScene/tCam** を新設（単位=天体半径）。歴史モードと同じ合成: メインcameraを原点+quaternion同期、
  renderer.autoClear=false で星空→tScene→ポスト。tCam.fov は hCam と同じ比率追従。
- **駅方式**: 天体を+X軸上に等間隔120で配置。**表示は現在の天体と飛行中の目的地だけ**
  （半径正規化した天体が同時に見えると相対サイズが嘘になるため。負荷対策も兼ねる）。
- 全天体 半径≒1 に正規化（訪問ごとにカメラが構図を作る=視点の自由。実サイズはカードで伝える）。
  カメラ距離は天体ごとに固定: 通常3.2 / 土星5.0(環込み) / 太陽4.0。距離変更なし=表面に埋まる事故なし。
- **照明**: 全駅 uSunDir=(-1,0,0) 固定（太陽駅が-X側にある想定と一致・実質正しい）。太陽本体は発光。
- **フリック判定（明文化）**: 指を離した瞬間、直前の移動速度が **0.9px/ms超 かつ 横成分が縦の1.5倍超**
  なら 右=次/左=前 の駅へ飛行(1.2s イージング)。それ以外はドラッグ(周回)。タップ(9px未満)=カード再表示。
- **土星の環**: RingGeometry+専用シェーダー。depthTest/depthWrite有効+透明部はdiscard
  （本体⇔環の前後関係をソートなしで正しく）。
- 地球・月は既存シェーダーの**別マテリアルインスタンス**（uniformsを複製・歴史モードへ影響ゼロ）。
- 到着判定=飛行イージング完了。カード10秒表示、次のフリックで即消える。
- fps予算: シェーダー追加ステップごとに `__U.bench` 実測し、超えたらoctave削減等で即調整。
