# 機能13「惑星と今夜の見どころ」設計書（2026-07-25）

DESIGN.md 機能13 の実装計画。実装者はこの1枚だけで作業できるように書いてある。

## ゴール（完成条件）
1. 水星・金星・火星・木星・土星の **本物の位置**（JPL近似軌道要素によるケプラー計算）を求め、
   🌍地球の夜空(gaze)モードの星空に **実等級・実色の点** として描く。
2. 惑星をタップ → カード「木星 ─ いま しし座に」「-2.3等 ／ 地球から 6.1億km」等。
3. 起動時に「今夜の見どころ」カード（月齢 ＋ いま見えている惑星）。
4. 宇宙遊泳(orbit)・歴史(history)・太陽系めぐり(tour)では **非表示**（遠くからは太陽の光に埋もれるのが本物）。
5. 既存の歴史モード用 `PLANETS`/`planetSprites`/`updatePlanets`（742行付近・雰囲気だけの点）は **一切触らない**。

## 座標系の前提（調査済み・再調査不要）
- ワールド座標＝**赤道直交座標(J2000)**。x=春分点方向, y=RA6h方向, z=天の北極。単位はパーセク。
  （根拠: `galToEq()` で天の川を銀河座標→この座標系へ変換している）
- gazeモードのカメラは原点(太陽)のすぐそば `camR≈0.02` に居て、`camera.up=(0,0,1)`。
- 星の描画は `starMat`（共用シェーダー）＋属性 `aMag`(見かけ等級) `aColor`(RGB 0〜1) `aPhase`(ゆらぎ位相)。
  `depthTest:false` / 加算合成。**惑星もこの `starMat` をそのまま共用**すれば見え方が星と揃う。

## 計算方式

### 1) 時刻
`JD = date.getTime()/86400000 + 2440587.5`（UTC）、`T = (JD - 2451545.0)/36525`（ユリウス世紀）。

### 2) JPL近似軌道要素（1800–2050年用・Standish）※この数値は**改変禁止**

### 3) 位置の求め方（各天体）
1. 要素 = 基準値 + 変化率 × T。
2. 平均近点角 `M = L - ϖ`（-180〜180 に正規化）、近日点引数 `ω = ϖ - Ω`。
3. ケプラー方程式 `E = M + e*sin(E)`（度で扱うなら `E = M + (180/π)e sin E`）をニュートン法で
   5〜8回反復（収束 1e-8 rad）。
4. 軌道面座標 `x' = a(cosE - e)`, `y' = a√(1-e²) sinE`。
5. 黄道直交座標(太陽中心)へ回転: ω → I → Ω の順（標準式）。
6. **地心黄道ベクトル** = 惑星ベクトル − 地球ベクトル。
7. 黄道→赤道: ε = 23.43928°。`xq = xe`, `yq = ye cosε − ze sinε`, `zq = ye sinε + ze cosε`。
8. RA = atan2(yq, xq)、Dec = asin(zq/|q|)、地球からの距離 d = |q|(au)。
9. 太陽の方向は「地球ベクトルの逆向き」で得る（見どころカード・離角判定に使う）。

### 4) 見かけの等級（標準式・α=位相角[度], r=太陽距離, d=地球距離）
```
水星 -0.36 + 5log10(r*d) + 0.038α - 0.000273α² + 0.000002α³
金星 -4.34 + 5log10(r*d) + 0.0009α + 0.000239α² - 0.00000065α³
火星 -1.51 + 5log10(r*d) + 0.016α
木星 -9.25 + 5log10(r*d) + 0.005α
土星 -8.88 + 5log10(r*d)          ← 環の傾きによる増減は省略（±0.4等ほどの誤差・コメントに明記）
```
位相角 α = 惑星から見た「太陽方向と地球方向の間の角」＝ `acos((r²+d²-R²)/(2 r d))`（R=地球の太陽距離）。

### 5) 実際の色（0〜1 RGB・肉眼での見え方に合わせる）
- 水星 (0.80, 0.76, 0.70) 灰みの白
- 金星 (1.00, 0.97, 0.88) まぶしい白
- 火星 (1.00, 0.52, 0.32) 赤橙
- 木星 (1.00, 0.93, 0.78) 淡いクリーム
- 土星 (0.98, 0.90, 0.68) 淡い金

### 7) 月齢（見どころカード用・位置は出さない）
`age = ((JD - 2451550.1) % 29.530588 + 29.530588) % 29.530588`。呼び名は
0〜1.5 新月／〜5.5 三日月のころ／〜9.5 上弦を過ぎたころ／〜13 十三夜のころ／〜16.5 満月のころ／
〜20 寝待月のころ／〜24 下弦のころ／それ以上 有明月のころ。

### 8) 見える／見えないの判定（見どころカード）
- 太陽からの離角 `elong`（地心での角距離）が **15°未満は「太陽に近すぎて見えない」** として載せない。
- 黄経差（惑星黄経 − 太陽黄経、0〜360）が 0〜180 → 「夕方の西の空」、180〜360 → 「明け方の東の空」。
- 離角 150°以上 → 「ひと晩じゅう見えます」。

## 実装（index.html への追加・部分Editのみ）
新セクション `// ═══════════════ 惑星（実際の軌道計算）と今夜の見どころ ═══════════════` を
**「星をタップ → 情報カード」セクションの直前**に追加し、以下を置く。

- `PL_ELEM` 定数表 ／ `planetPositions(date)` → `[{key,name,ra,dec,dist,mag,ecLon,elong,con,vis}]` ＋ 太陽情報
- `THREE.Points`（5点・`starMat` 共用・`frustumCulled=false`・`renderOrder=5`）を `scene` に追加
- `updatePlanetSky()`: 位置と等級を再計算して属性を更新（**60秒ごと**、モード切替時にも）
- メインループ内: `planetPoints.visible = (mode === 'gaze')`、gaze時のみ
  `planetPoints.position.copy(camera.position)`（ローカル座標は方向ベクトル×100pc。視差誤差 0.01°以下）
- `pickStar()` の先頭付近（history/tour の早期returnの後）に **惑星の当たり判定を先に**入れる。
  ヒットしたら惑星カードを出して return（星より優先）。しきい値は既存の `limit` と同じ考え方で。
- 起動1.5秒後に「今夜の見どころ」カードを表示（12秒で自動消灯・既存カードと同じ `.n/.s/.d/.y` 構造）。

### __U フック（必須）
```
__U.planets()        // 惑星＋太陽の RA/Dec/等級/星座/離角の一覧（数値で返す）
__U.tonight()        // 見どころカードの本文をプレーンテキストで
__U.setPlanetDate(s) // 検証用に日時を固定（null で現在時刻に戻す）→ 即再計算
__U.planetPick(name) // タップ再現（カード表示）
```

## 検証（実装者が必ず行う・結果を報告）
1. `__U.setPlanetDate('2026-07-25T12:00:00Z')` → 太陽の黄経 **122.2°±0.3** になること（強い検算）。
2. `__U.setPlanetDate('2000-01-01T12:00:00Z')` → 太陽の黄経 **280.0°±0.3**。
3. 惑星5個の RA/Dec/等級/星座が妥当（金星は-4等前後、木星-2等前後、土星0〜1等前後）。
4. gazeモードだけで見え、orbit/history/tour では `visible=false`。
5. コンソールにエラーが出ていない・`__uchuStarted===true`。
