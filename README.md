# 宇宙 — 本物の星空アプリ（プロトタイプ第1弾）

眺めているだけで癒される「実在の宇宙」生成アプリ。旧作 `Desktop\宇宙.html` の
「星が無限に生まれ、ブラックホールが呑み込んでバランスを取る」という魂を継承しつつ、
星空そのものを本物の天文データで作り直したもの。Android アプリ化（バナー広告収益）が最終目標。

## ファイル
- `index.html` — アプリ本体（three.js r160 を CDN から読込。初回のみネット接続が必要）
- `stars.js` — 実在の星データ 8,920個（313KB、自動生成。手で編集しない）
- `CLAUDE.md` — **作業ルール（AIは着手前に必読・自動読込）**
- `DESIGN.md` — **機能1〜20の完全設計図（コード地図・データ入手先・実装手順・検証法・落とし穴）**

## 使っている本物のデータ
- 星: HYG Database v4.1（https://github.com/astronexus/HYG-Database）から
  肉眼で見える 6.5等級までの 8,920個。位置(3D)・明るさ・色(B-V色指数→色温度→RGB)・固有名(358個)すべて実データ。
- 星座線: Stellarium の modern 星座（88星座、692本、HIP番号で実星に接続）。
- 銀河・星雲: アンドロメダ銀河・大小マゼラン雲・オリオン大星雲・すばる を実際の位置に配置。
- 天の川: 実際の銀河座標系に沿ってプロシージャル生成（微光星38,000個＋乳白色のもや）。

## 機能
- **2つのカメラモード**(2026-07-03):
  - 宇宙遊泳(既定): **フリックの法則(2026-07-07確定・ユーザー承認済み)** — 指を離した瞬間に1ダイブ発動。
    ①フリック方向へ少しホップ(hopTilt=0.21)した奥へ超スピード直進(距離比例・最大vMax=65)
    ②勢いが尽きたら(壁rMax=42での強制減速も含む)“自分を中心に”フリック方向へゆっくり回頭
    (turnSlow=0.35rad/s・中心をとらえるまで約8秒) ③中心をとらえたら旋回おわり→中心を見る漂いへ。
    回頭中の再フリック=見ている奥へ即再ダイブ。上下左右斜めすべて「フリックの向き=回頭の向き」。
    ⚠️画面右は `cross(viewTarget, camUp)` の順（逆にすると左右が鏡写しになるバグ・実証済み）。
    漂い中は弱い中心引力(ORB.K)+軌道面の歳差(precAxis)で無限の角度の星々を巡る。左右バンクゆれ付き。
    左端の縦スライダーは漂いの速さ0.4〜4.0倍(既定1.7)。検証フック `__U.wander()`(speed/camR/diving)。
    ※方位角+lookAt方式(極で縦制限)→大円回転(奥行き不足)→中心ダイブ(前進感なし)を経て現法則へ。
  - 🌍地球の夜空: 太陽の位置に降りて、地上で見えるままの本物の空(星座の形が正しい場所)。
  - **星の明るさはカメラからの実距離で毎コマ再計算**(絶対等級ベース)=本物の奥行き・視差。
- **星座図鑑**(🔍さがす): 88星座を五十音で検索→地球の夜空モードでその星座へ視線移動+線をハイライト
  +紹介カード(神話ひとこと・見頃の月・いちばん明るい星)。CON_INFO に88星座の解説文。
- **太陽**が原点に実在の色・等級で存在(遊泳中は画面中央タップで「私たちの母星」カード)
- **現在地表示**(右下): 「太陽から◯光年/最寄りの星」。地球モード中はその旨表示。
- 星タップ → 名前(日本語)・星座・地球からの距離・等級・「光が出発した年」カード
- **BHは隠しモード**(2026-07-03・リアルさ優先で既定OFF): ●BHボタンで超早回し銀河モード開始/停止。
  OFF中は偽物の星ゼロの100%実在宇宙。ON中のみ誕生/消滅カウンター表示。
- **⏳歴史モード**(2026-07-03): 地球46億年の旅。実史実17時代(マグマの海→月の誕生→海→生命→
  全球凍結×2→カンブリア爆発→緑の上陸→パンゲア→大絶滅→恐竜→小惑星衝突→人類→現在)を
  約3分でループ。地球はシェーダー生成(海面/氷/雲/マグマ/夜の街あかりを時代ごとに補間)、
  月は実史実どおり誕生時は近く(17地球半径)→現在60へ遠ざかる。背景は本物の星空と合成
  (別シーンhScene・単位=地球半径・カメラ向き同期)。自動カメラは昼側中心にゆらゆら。
  ピンチ/ホイールで背景の星をズームすると、地球・月も同じ倍率で連動して大小する
  (hCam.fovを星カメラに追従。基準62↔55の比を保持=起動時の見え方は不変)。
  他の惑星(水星〜土星)は「地球の横から見た"さまよう明るい点"」として実在の色で黄道面に配置
  (金星=白く最輝/火星=赤/木星=クリーム/土星=淡黄)。細かい球にはしない=地球の傍からは点にしか
  見えないのが本物。ゆっくり漂い、地球の裏に回ると隠れる。歴史モード中だけ表示。
  検証用フック `__U.hist(0〜1)` で時点ジャンプ、`__U.histFreeze(true)` で時代/カメラ静止、
  `__U.planetsDbg()` で惑星の画面位置(※終端間際は数秒でループ一周に注意)。
- **🪐太陽系めぐり**(2026-07-08・主要6天体の第1弾): 太陽→地球→月→火星→木星→土星を
  リアルな3D球で訪ねる新モード。左右フリックで前/次の天体へ飛行(1.2s・**端はループ**=土星の次は太陽)・
  ドラッグで周回・ピンチで寄る(fov比率追従)。放置中はどの天体でも同じゆったり漂う周回(浮遊感)。
  飛行中はカメラを昼側が見える定番構図へ自動で戻す(フリックで向きが暴れて夜側に着く事故の防止)。
  **縦フリックで「引き(ぜんたい)＝軌道図ビュー」**(2026-07-11): 太陽を中心に軌道の輪(ORB_VIEW)が
  広がり、地球・火星・木星・土星が**実周期の比(1地球年=120秒)**で公転、**月は地球のまわり**を実比13倍速で
  回る俯瞰図。大きさ(WIDE_S)と軌道半径は見た目重視の縮めたイメージ(大小の順序は本物・HUDに明記)。
  太陽は赤々と燃える配色(heat式+赤コロナ)。星をタップ=解説カード(画面上の最近傍で小星も拾いやすく)、
  同じ星をもう一度=接近、空タップ=カード閉じ。カードは触れた瞬間に閉じる(全モード共通)。
  もう一度縦フリックで今の天体へ戻る。引き中は横フリック無効。
  検証フック: `__U.tourWideSet(b)` / `__U.tourTick(dt)`(描画ループなしで1コマ進める) / tourStateにwide。
  ※UI自動消去中のボタンは pointer-events:none(見えないボタンを誤タップして別モードへ飛ぶ事故の修正)。見た目は全てプロシージャルシェーダーで実在準拠:
  太陽=粒状斑+周縁減光+コロナ(赤く燃える配色)／**地球・月=NASA由来の実写マップ**(tex/にローカル同梱・
  2026-07-11) にシェーダーで動く雲・海の照り返し・青い大気のフチ・夕焼けの帯・夜の街あかり・
  月は影の際を柔らかく＝めちゃリアル路線。歴史モードの地球・月は従来どおりプロシージャル(46億年の変化用)／
  火星=赤い大地+極冠+薄い大気／木星=乱流縞+大赤斑(南緯22°)／土星=淡い縞+環(実比率1.24〜2.27R・
  カッシーニ/エンケの間隙・discard深度処理)。実自転軸傾斜・実自転周期の3600倍速(1時間=1秒)。
  照明は全駅-X=太陽方向で統一。表示は現在の天体+飛行中の出発元のみ(正規化サイズの嘘を見せない)。
  到着時に日本語紹介カード(実データ)・タップで再表示。フリック判定=離した瞬間の速度0.9px/ms超かつ
  横>縦1.5倍。検証フック: `__U.tourJump(i)` / `__U.tourState()` / `__U.scenes`。
  設計書: docs/plans/2026-07-08-taiyokei-meguri.md（第2弾候補: 水星・金星・天王星・海王星）。
- **♪環境音**(2026-07-03): 生成式アンビエント(音源ファイル不要)。低音ドローン3本+
  ときどき五音音階の鈴+宇宙的残響。おとボタンでON/OFF。
- 星座線 ON/OFF（✦ボタン）
- ブラックホール: 重力レンズ＋光子リング＋降着円盤(ドップラー効果)。空を旅する。●BHボタンでカメラが自動誘導。
- **銀河形成シミュレーション**(2026-07-02追加・前作の魂の本実装): 星はBH周囲の雲から
  「回転の勢い(角運動量)+乱流の揺らぎ」を持ってほぼ静止で誕生(自力で飛ぶのは1%の流れ星のみ)。
  BHの重力+星同士の引力(重心近似)+円軌道への緩やかな収束(ガス摩擦の代役)で、
  **約15分かけて渦巻き銀河に成長**。以後は「1.2秒に1個生まれ、寿命の来た星が
  死の螺旋(決定論的・約20〜30秒)でBHへ還る」永久循環。左下に誕生/消滅カウンター。
  ⚠️ BH質量は固定(900)。質量成長や吸い込み強化を入れると暴走(全呑み)か凍結に転ぶ
  不安定系なので、変更時は `__U.advanceSim(秒)` で90分相当の長期テストをすること
  (90分テスト済み: 個体数約700で安定・中央値半径8.7を維持)。
- 全画面ボタン（⛶）。UIは3秒で自動的に消え、タップで復帰（没頭モード）。

## 動作確認
- `.claude/launch.json` の `uchu-app`（ポート8790）でプレビュー起動。
- コンソールの `__U` に調整用フック（bench / testPick / setLonLat / dbg / dist / advanceSim / sim.speed / setWander / wander / 各uniform）。
  `advanceSim(1800)` = 30分ぶん一気に時間を進める（画面非表示でも確実・検証はこれを使う）。
