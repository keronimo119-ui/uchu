# 宇宙 — 本物の星空アプリ（プロトタイプ第1弾）

眺めているだけで癒される「実在の宇宙」生成アプリ。旧作 `Desktop\宇宙.html` の
「星が無限に生まれ、ブラックホールが呑み込んでバランスを取る」という魂を継承しつつ、
星空そのものを本物の天文データで作り直したもの。Android アプリ化（バナー広告収益）が最終目標。

## ファイル
- `index.html` — アプリ本体（three.js r160 を CDN から読込。初回のみネット接続が必要）
- `stars.js` — 実在の星データ 8,920個（313KB、自動生成。手で編集しない）
- `CLAUDE.md` — **作業ルール（AIは着手前に必読・自動読込）**
- `DESIGN.md` — **機能1〜20の完全設計図（コード地図・データ入手先・実装手順・検証法・落とし穴）**

## 使っている本物のデータ
- 星: HYG Database v4.1（https://github.com/astronexus/HYG-Database）から
  肉眼で見える 6.5等級までの 8,920個。位置(3D)・明るさ・色(B-V色指数→色温度→RGB)・固有名(358個)すべて実データ。
- 星座線: Stellarium の modern 星座（88星座、692本、HIP番号で実星に接続）。
- 銀河・星雲: アンドロメダ銀河・大小マゼラン雲・オリオン大星雲・すばる を実際の位置に配置。
- 天の川: 実際の銀河座標系に沿ってプロシージャル生成（微光星38,000個＋乳白色のもや）。

## 機能
- **2つのカメラモード**(2026-07-03):
  - 宇宙遊泳(既定): 視点は常に空間の中心(太陽)を注視。フリックで楕円軌道を長く滑り、
    数秒ごとにランダムな向き・速さへ切り替わる漂い。半径2.5〜27pcを呼吸するように変化。
  - 🌍地球の夜空: 太陽の位置に降りて、地上で見えるままの本物の空(星座の形が正しい場所)。
  - **星の明るさはカメラからの実距離で毎コマ再計算**(絶対等級ベース)=本物の奥行き・視差。
- **星座図鑑**(🔍さがす): 88星座を五十音で検索→地球の夜空モードでその星座へ視線移動+線をハイライト
  +紹介カード(神話ひとこと・見頃の月・いちばん明るい星)。CON_INFO に88星座の解説文。
- **太陽**が原点に実在の色・等級で存在(遊泳中は画面中央タップで「私たちの母星」カード)
- **現在地表示**(右下): 「太陽から◯光年/最寄りの星」。地球モード中はその旨表示。
- 星タップ → 名前(日本語)・星座・地球からの距離・等級・「光が出発した年」カード
- **BHは隠しモード**(2026-07-03・リアルさ優先で既定OFF): ●BHボタンで超早回し銀河モード開始/停止。
  OFF中は偽物の星ゼロの100%実在宇宙。ON中のみ誕生/消滅カウンター表示。
- **⏳歴史モード**(2026-07-03): 地球46億年の旅。実史実17時代(マグマの海→月の誕生→海→生命→
  全球凍結×2→カンブリア爆発→緑の上陸→パンゲア→大絶滅→恐竜→小惑星衝突→人類→現在)を
  約3分でループ。地球はシェーダー生成(海面/氷/雲/マグマ/夜の街あかりを時代ごとに補間)、
  月は実史実どおり誕生時は近く(17地球半径)→現在60へ遠ざかる。背景は本物の星空と合成
  (別シーンhScene・単位=地球半径・カメラ向き同期)。自動カメラは昼側中心にゆらゆら。
  検証用フック `__U.hist(0〜1)` で時点ジャンプ(※終端間際は数秒でループ一周に注意)。
- **♪環境音**(2026-07-03): 生成式アンビエント(音源ファイル不要)。低音ドローン3本+
  ときどき五音音階の鈴+宇宙的残響。おとボタンでON/OFF。
- 星座線 ON/OFF（✦ボタン）
- ブラックホール: 重力レンズ＋光子リング＋降着円盤(ドップラー効果)。空を旅する。●BHボタンでカメラが自動誘導。
- **銀河形成シミュレーション**(2026-07-02追加・前作の魂の本実装): 星はBH周囲の雲から
  「回転の勢い(角運動量)+乱流の揺らぎ」を持ってほぼ静止で誕生(自力で飛ぶのは1%の流れ星のみ)。
  BHの重力+星同士の引力(重心近似)+円軌道への緩やかな収束(ガス摩擦の代役)で、
  **約15分かけて渦巻き銀河に成長**。以後は「1.2秒に1個生まれ、寿命の来た星が
  死の螺旋(決定論的・約20〜30秒)でBHへ還る」永久循環。左下に誕生/消滅カウンター。
  ⚠️ BH質量は固定(900)。質量成長や吸い込み強化を入れると暴走(全呑み)か凍結に転ぶ
  不安定系なので、変更時は `__U.advanceSim(秒)` で90分相当の長期テストをすること
  (90分テスト済み: 個体数約700で安定・中央値半径8.7を維持)。
- 全画面ボタン（⛶）。UIは7秒で自動的に消え、タップで復帰（没頭モード）。

## 動作確認
- `.claude/launch.json` の `uchu-app`（ポート8790）でプレビュー起動。
- コンソールの `__U` に調整用フック（bench / testPick / setLonLat / dbg / dist / advanceSim / sim.speed / 各uniform）。
  `advanceSim(1800)` = 30分ぶん一気に時間を進める（画面非表示でも確実・検証はこれを使う）。
- 実測: 描画 0.4ms/コマ（60FPSの40倍の余裕）。

## stars.js の再生成方法
